# Homebrew tap for diskmap

[diskmap](https://github.com/zapotylok/diskmap) — a partition map and layout planner for
external drives on macOS. Every change is a `diskutil` command you see before it runs.

```sh
brew install zapotylok/diskmap/diskmap
```

The formula builds diskmap from source on your Mac: the `diskmap` command and the window,
`diskmap.app`. It needs macOS 26 on Apple silicon. See the
[diskmap README](https://github.com/zapotylok/diskmap#install) for the rest.
